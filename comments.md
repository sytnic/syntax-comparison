# Comments. Комментарии

### Kotlin

```kotlin
// This is a comment
println("Hello World") 

/* The code below will print the words Hello World
to the screen, and it is amazing */
println("Hello World") 
```

### PHP

```php
    <?php

    /* Многострочный
        комментарий    
    */ 
    ?>
```

### Python

```py
#This is a comment
print("Hello, World!")

print("Hello, World!") #This is a comment
```

Python does not really have a syntax for multiline comments.

```py
#This is a comment
#written in
#more than just one line
print("Hello, World!")
```
But Since Python will ignore string literals that are not assigned to a variable, you can add a multiline string (triple quotes) in your code, and place your comment inside it.  
Т.е. речь о строковом литерале, куске форматированного текта. Если он не присвоен переменной, Python его игнорирует.  

```py
"""
This is a comment
written in
more than just one line
"""
print("Hello, World!") 
```
