# Loops

## Kotlin

### Kotlin While

```kotlin
fun main() {
  var i = 0
  while (i < 5) {
    println(i)
    i++
  }
}
```

### Do..While Loop

```kotlin
fun main() {
    var i = 0
    do {
          println(i)
          i++
      }
    while (i < 5) 
}
```

### For Loop

```kotlin
fun main() {
  val cars = arrayOf("Volvo", "BMW", "Ford", "Mazda")
  for (x in cars) {
    println(x)
  }
}
/*
Volvo
BMW
Ford
Mazda
*/
```

```kotlin
fun main() {
  val nums = arrayOf(1, 5, 10, 15, 20)
  for (x in nums) {
    println(x)
  }
}
/*
1
5
10
15
20*/
```
